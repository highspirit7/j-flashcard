# 덱 상세·단어 관리 화면 사양서

## 1. 화면 목적

사용자가 선택한 덱의 카드 목록을 확인하고, 카드를 추가·편집·삭제하거나 학습을 시작할 수 있도록 한다. 또한 덱 자체의 정보를 수정하거나 덱을 삭제하는 기능을 제공한다.

## 2. 진입 및 이탈

### 진입

- 홈·덱 목록 화면에서 덱 이름을 클릭하면 이 화면으로 이동한다.
- 단어 생성·편집 화면에서 저장 또는 취소 후 이 화면으로 돌아온다.
- 유효한 세션이 있는 사용자만 접근할 수 있다.

### 이탈

- 뒤로가기 또는 홈 버튼을 클릭하면 홈·덱 목록 화면으로 이동한다.
- '새 카드 추가' 버튼을 클릭하면 단어 생성 페이지로 이동한다.
- 단어 행의 편집 버튼을 클릭하면 단어 편집 페이지로 이동한다.
- '학습 시작' 버튼을 클릭하면 해당 덱의 학습 화면으로 이동한다.
- 덱 삭제를 확인하면 덱이 삭제되고 홈·덱 목록 화면으로 이동한다.
- 로그아웃하면 세션을 종료하고 로그인 화면으로 이동한다.

## 3. 화면 구성

| 영역        | 요소                    | 설명                                                             |
| ----------- | ----------------------- | ---------------------------------------------------------------- |
| 헤더        | 뒤로가기 버튼           | 홈·덱 목록 화면으로 이동한다.                                    |
| 헤더        | 덱 이름, 설명 | 현재 덱의 기본 정보를 표시한다.                                  |
| 헤더        | 더보기(⋮) 버튼          | 덱 편집, 덱 삭제 메뉴를 연다.                                    |
| 메뉴        | 덱 편집                 | 덱 이름, 설명을 수정하는 모달 또는 화면을 연다.        |
| 메뉴        | 덱 삭제                 | 덱 삭제 확인 UI를 표시한다.                                      |
| 콘텐츠 헤더 | 학습 시작 버튼          | 해당 덱의 학습 화면으로 이동한다.                                |
| 콘텐츠 헤더 | 새 카드 추가 버튼       | 단어 생성 페이지로 이동한다.                                     |
| 목록 영역   | 단어 목록 또는 행       | 단어, 읽기, 뜻, 품사, 학습 상태(New/Learning/Review)를 표시한다. |
| 단어 행     | 편집 버튼               | 해당 단어의 단어 편집 페이지로 이동한다.                         |
| 단어 행     | 삭제 버튼               | 단어 삭제 확인 UI를 표시한다.                                    |
| 모달        | 덱 삭제 확인 모달       | 삭제 대상 덱 이름을 표시하고 확인 또는 취소한다.                 |
| 모달        | 단어 삭제 확인 모달     | 삭제 대상 단어를 표시하고 확인 또는 취소한다.                    |

덱 삭제와 단어 삭제는 같은 화면 안에서도 서로 다른 대상을 가리키므로, 확인 모달에 삭제 대상(덱 이름 또는 단어)을 명확히 표시하여 혼동을 방지한다.

## 4. 표시 데이터

- 덱 이름, 설명
- 덱에 포함된 전체 카드 수
- 덱의 New, Learning, Review 카드 수
- 각 카드의 단어, 읽기, 뜻, 품사, 학습 상태
- 각 카드의 예문 존재 여부(목록에서는 요약, 상세 내용은 단어 편집 페이지에서 확인)

- 카드 목록은 현재 로그인한 사용자가 소유한 덱의 데이터만 표시한다.
- 카드 수와 목록을 불러올 수 없는 경우 잘못된 값을 성공 상태처럼 표시하지 않는다.

## 5. 사용자 동작

| 사용자 동작            | 시스템 처리                           | 기대 결과                                 |
| ---------------------- | ------------------------------------- | ----------------------------------------- |
| 뒤로가기 버튼 클릭     | 화면 전환을 준비한다.                 | 홈·덱 목록 화면으로 이동한다.             |
| 더보기(⋮) 버튼 클릭    | 덱 편집·삭제 메뉴를 연다.             | 메뉴 항목을 선택할 수 있다.               |
| 덱 편집 선택           | 덱 편집 입력 UI를 연다.               | 덱 이름, 설명을 수정할 수 있다. |
| 덱 편집 저장           | 입력값을 검증하고 덱 정보를 갱신한다. | 갱신된 정보가 화면에 표시된다.            |
| 덱 삭제 선택           | 덱 삭제 확인 모달을 연다.             | 삭제 대상 덱 이름을 확인할 수 있다.       |
| 덱 삭제 확인           | 해당 덱의 삭제를 요청한다.            | 삭제 후 홈·덱 목록 화면으로 이동한다.     |
| 덱 삭제 취소           | 삭제 요청을 취소한다.                 | 덱과 목록이 변경되지 않는다.              |
| 학습 시작 버튼 클릭    | 해당 덱의 학습 대상 카드를 조회한다.  | 해당 덱의 학습 화면으로 이동한다.         |
| 새 카드 추가 버튼 클릭 | 단어 생성 페이지로 이동을 준비한다.   | 단어 생성 페이지가 표시된다.              |
| 단어 행 편집 버튼 클릭 | 선택한 단어 정보를 불러온다.          | 단어 편집 페이지로 이동한다.              |
| 단어 행 삭제 버튼 클릭 | 단어 삭제 확인 모달을 연다.           | 삭제 대상 단어를 확인할 수 있다.          |
| 단어 삭제 확인         | 해당 단어의 삭제를 요청한다.          | 단어가 목록에서 제거된다.                 |
| 단어 삭제 취소         | 삭제 요청을 취소한다.                 | 단어와 목록이 변경되지 않는다.            |

## 6. 화면 상태

### 6.1 초기 상태

- 덱 기본 정보와 화면 제목을 표시한다.
- 카드 목록 조회를 시작한다.
- 카드 목록을 불러오는 동안 목록 영역에 로딩 상태를 표시한다.

### 6.2 카드 목록 표시 상태

- 현재 덱에 속한 카드만 표시한다.
- 각 카드의 기본 정보와 학습 상태를 표시한다.
- 편집·삭제 버튼으로 각 카드를 관리할 수 있다.

### 6.3 빈 카드 목록 상태

- 덱에 카드가 없으면 카드가 없다는 안내를 표시한다.
- '새 카드 추가' 동작을 바로 실행할 수 있도록 한다.
- 카드가 없는 상태를 오류 상태와 구분한다.
- 카드가 없어도 학습 시작 버튼은 학습할 카드가 없다는 결과를 안내한다.

### 6.4 덱 편집 상태

- 덱 이름, 설명을 수정할 수 있다.
- 저장하지 않고 취소하거나 닫으면 변경 사항이 저장되지 않는다.
- 저장 요청 중에는 중복 제출을 방지한다.

### 6.5 덱 삭제 확인 상태

- 삭제 대상 덱의 이름을 표시하여 사용자가 대상을 확인할 수 있도록 한다.
- 확인 전에는 덱을 삭제하지 않는다.
- 취소하면 화면과 덱 데이터가 변경되지 않는다.
- 덱을 삭제하면 해당 덱에 포함된 카드도 함께 삭제된다.
- 삭제된 카드의 학습 기록(복습 로그)은 삭제하지 않고 보존한다.

### 6.6 단어 삭제 확인 상태

- 삭제 대상 단어를 표시하여 사용자가 대상을 확인할 수 있도록 한다.
- 확인 전에는 단어를 삭제하지 않는다.
- 취소하면 목록과 단어 데이터가 변경되지 않는다.
- 삭제된 단어의 학습 기록(복습 로그)은 덱 삭제와 동일하게 삭제하지 않고 보존한다.

### 6.7 삭제 요청 중

- 삭제 요청 중인 대상(덱 또는 단어)은 중복 삭제를 요청할 수 없도록 처리한다.
- 사용자가 삭제 요청 진행 중임을 알 수 있도록 표시한다.

### 6.8 오류 상태

- 카드 목록 조회에 실패하면 오류 메시지와 재시도 동작을 표시한다.
- 덱 편집에 실패하면 입력한 값을 유지하고 다시 시도할 수 있도록 한다.
- 덱 삭제에 실패하면 덱을 제거하지 않고 화면에 남아 오류를 표시한다.
- 단어 삭제에 실패하면 해당 단어를 목록에서 제거하지 않고 오류를 표시한다.
- 오류가 발생한 요청을 성공한 것으로 처리하지 않는다.

### 6.9 세션 만료 또는 권한 없음 상태

- 세션이 만료되었거나 현재 사용자가 소유하지 않은 덱이면 카드 데이터를 조회하지 않는다.
- 로그인 화면 또는 홈·덱 목록 화면으로 이동한다.
- 덱 정보나 오류 원인을 인증되지 않은 상태에서 노출하지 않는다.

## 7. 입력 및 검증

| 필드    | 필수 여부 | 검증                            |
| ------- | --------- | ------------------------------- |
| 덱 이름 | 필수      | 비어 있지 않아야 한다.          |
| 덱 설명 | 선택      | 입력하지 않아도 저장할 수 있다. |

- 덱 이름이 비어 있으면 편집 저장 요청을 보내지 않는다.
- 덱 삭제와 단어 삭제는 각각 별도의 확인 절차를 거친 뒤에만 요청을 보낸다.

## 8. 오류 처리

| 상황                     | 처리                                                      |
| ------------------------ | --------------------------------------------------------- |
| 카드 목록 조회 실패      | 오류 메시지와 재시도 동작을 표시한다.                     |
| 덱 이름이 비어 있음      | 덱 이름 필드에 오류를 표시하고 저장 요청을 보내지 않는다. |
| 덱 편집 실패             | 입력값을 유지하고 저장 실패 메시지를 표시한다.            |
| 덱 삭제 취소             | 아무 데이터도 삭제하지 않고 화면을 유지한다.              |
| 덱 삭제 실패             | 덱을 제거하지 않고 실패 메시지를 표시한다.                |
| 단어 삭제 취소           | 아무 데이터도 삭제하지 않고 목록을 유지한다.              |
| 단어 삭제 실패           | 단어를 목록에서 제거하지 않고 실패 메시지를 표시한다.     |
| 세션 만료 또는 권한 없음 | 로그인 화면 또는 홈·덱 목록 화면으로 이동한다.            |
| 학습 대상 조회 실패      | 학습 화면으로 이동하지 않고 현재 화면에 오류를 표시한다.  |

오류 메시지는 사용자가 다음 행동을 알 수 있도록 작성하며, 데이터베이스나 인증 시스템의 내부 정보를 노출하지 않는다.

## 9. 완료 조건

- 현재 덱에 속한 카드 목록만 표시된다.
- 각 카드의 단어, 읽기, 뜻, 품사, 학습 상태가 표시된다.
- 카드 목록을 불러오는 동안 로딩 상태가 표시된다.
- 카드가 없을 때 오류와 구분되는 빈 상태가 표시된다.
- 더보기(⋮) 메뉴를 통해 덱 편집과 덱 삭제에 접근할 수 있다.
- 덱 이름을 비운 채로는 덱 편집을 저장할 수 없다.
- 덱 삭제 전 삭제 대상을 확인할 수 있고, 취소하면 데이터가 유지된다.
- 삭제를 확인한 덱이 목록과 데이터베이스에서 제거되고 홈·덱 목록 화면으로 이동한다.
- 단어 삭제 전 삭제 대상을 확인할 수 있고, 취소하면 데이터가 유지된다.
- 삭제를 확인한 단어가 목록과 데이터베이스에서 제거된다.
- '새 카드 추가' 버튼을 클릭하면 단어 생성 페이지로 이동한다.
- 단어 행의 편집 버튼을 클릭하면 단어 편집 페이지로 이동한다.
- '학습 시작' 버튼을 클릭하면 해당 덱의 학습 화면으로 이동한다.
- 카드 목록 조회, 덱 편집·삭제, 단어 삭제에 실패하면 실패 상태를 표시하고 성공한 것처럼 화면을 변경하지 않는다.
- 세션이 만료되었거나 다른 사용자의 덱에 접근하면 카드 데이터가 노출되지 않는다.
