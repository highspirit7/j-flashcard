# 로그인 화면 사양서

## 1. 화면 목적

등록된 사용자가 인증 정보를 입력하여 J-Flashcard에 로그인하고, 로그인한 사용자 전용 화면에 접근할 수 있도록 한다.

## 2. 진입 및 이탈

### 진입

- 인증되지 않은 사용자가 앱에 접근하면 로그인 화면으로 이동한다.
- 로그인하지 않은 사용자가 보호된 화면에 접근하면 로그인 화면으로 이동한다.
- 이미 유효한 세션이 있는 사용자가 로그인 화면에 접근하면 홈·덱 목록 화면으로 이동한다.

### 이탈

- 로그인에 성공하면 홈·덱 목록 화면으로 이동한다.
- 인증 실패 또는 저장된 세션이 없으면 로그인 화면에 남는다.

## 3. 화면 구성

| 영역      | 요소               | 설명                                                     |
| --------- | ------------------ | -------------------------------------------------------- |
| 헤더      | 앱 이름            | J-Flashcard를 표시한다.                                  |
| 입력 영역 | 사용자명 입력 필드 | 로그인에 사용할 사용자명을 입력한다.                     |
| 입력 영역 | 비밀번호 입력 필드 | 로그인에 사용할 비밀번호를 입력한다. 입력 내용은 숨긴다. |
| 실행 영역 | 로그인 버튼        | 입력한 인증 정보로 로그인을 요청한다.                    |
| 안내 영역 | 오류 메시지        | 입력 오류 또는 로그인 실패 원인을 표시한다.              |

## 4. 표시 데이터

- 사용자명 입력값
- 비밀번호 입력값
- 로그인 요청 진행 상태
- 인증 실패 또는 네트워크 오류 메시지

비밀번호는 화면에 평문으로 표시하지 않으며, 로그인 성공 후에도 화면이나 클라이언트 상태에 표시하지 않는다.

## 5. 사용자 동작

| 사용자 동작             | 시스템 처리                         | 기대 결과                                 |
| ----------------------- | ----------------------------------- | ----------------------------------------- |
| 사용자명 입력           | 입력값을 변경한다.                  | 입력한 사용자명이 필드에 표시된다.        |
| 비밀번호 입력           | 입력값을 변경한다.                  | 입력한 비밀번호가 숨겨진 형태로 표시된다. |
| 로그인 버튼 클릭        | 입력값을 검증한 뒤 인증을 요청한다. | 성공하면 홈·덱 목록 화면으로 이동한다.    |
| 로그인 버튼을 연속 클릭 | 진행 중인 요청이 있는지 확인한다.   | 중복 로그인 요청이 발생하지 않는다.       |
| Enter 키 입력           | 로그인 요청을 실행한다.             | 로그인 버튼 클릭과 같은 결과가 발생한다.  |

## 6. 화면 상태

### 6.1 초기 상태

- 사용자명과 비밀번호 입력 필드는 비어 있다.
- 로그인 버튼을 사용할 수 있다.
- 오류 메시지는 표시하지 않는다.

### 6.2 입력 오류 상태

- 필수 입력값이 비어 있으면 로그인 요청을 보내지 않는다.
- 비어 있는 필드에 입력이 필요하다는 오류를 표시한다.
- 사용자는 오류를 수정한 뒤 다시 로그인할 수 있다.

### 6.3 로그인 요청 중

- 로그인 요청이 진행되는 동안 로그인 버튼을 비활성화한다.
- 중복 요청을 방지한다.
- 사용자가 요청 진행 중임을 알 수 있는 표시를 제공한다.

### 6.4 인증 실패 상태

- 로그인 화면에 남는다.
- 사용자가 인증 정보를 다시 입력할 수 있다.
- 인증 정보가 올바르지 않다는 오류 메시지를 표시한다.
- 비밀번호를 오류 메시지에 포함하지 않는다.

### 6.5 로그인 성공 상태

- 유효한 세션을 저장하거나 유지한다.
- 홈·덱 목록 화면으로 이동한다.
- 로그인 화면으로 돌아왔을 때 유효한 세션을 다시 인증하지 않는다.

### 6.6 네트워크 또는 서버 오류 상태

- 로그인 화면에 남는다.
- 일시적인 오류임을 알리는 메시지를 표시한다.
- 사용자가 다시 시도할 수 있다.
- 실패한 요청을 성공한 것으로 처리하지 않는다.

## 7. 입력 및 검증

| 필드     | 필수 여부 | 검증                   |
| -------- | --------- | ---------------------- |
| 사용자명 | 필수      | 비어 있지 않아야 한다. |
| 비밀번호 | 필수      | 비어 있지 않아야 한다. |

- 입력값 앞뒤의 불필요한 공백 처리 방식은 구현 전에 결정한다.
- 비밀번호는 입력 중인 내용이 노출되지 않아야 한다.
- 서버 인증 오류와 입력값 누락 오류를 구분하여 처리한다.

## 8. 오류 처리

| 상황                         | 처리                                                            |
| ---------------------------- | --------------------------------------------------------------- |
| 사용자명이 비어 있음         | 사용자명 입력 필드에 오류를 표시하고 인증 요청을 보내지 않는다. |
| 비밀번호가 비어 있음         | 비밀번호 입력 필드에 오류를 표시하고 인증 요청을 보내지 않는다. |
| 인증 정보가 올바르지 않음    | 로그인 화면에 인증 실패 메시지를 표시한다.                      |
| 네트워크 또는 서버 요청 실패 | 재시도할 수 있는 오류 메시지를 표시한다.                        |
| 세션 생성 또는 복원 실패     | 로그인 화면에 남기고 사용자가 다시 로그인할 수 있도록 한다.     |

오류 메시지는 비밀번호나 인증 시스템의 내부 정보를 노출하지 않아야 한다.

## 9. 완료 조건

- 인증되지 않은 사용자가 앱에 접근하면 로그인 화면이 표시된다.
- 사용자명과 비밀번호를 입력할 수 있다.
- 필수 입력값이 누락되면 인증 요청이 전송되지 않고 오류가 표시된다.
- 올바른 인증 정보로 로그인하면 홈·덱 목록 화면으로 이동한다.
- 잘못된 인증 정보로 로그인하면 화면에 남고 재입력할 수 있다.
- 로그인 요청 중에는 중복 요청을 보낼 수 없다.
- 네트워크 또는 서버 오류가 발생하면 실패 상태를 표시하고 재시도할 수 있다.
- 로그인 성공 후 새로고침해도 유효한 세션이 유지된다.
- 로그인한 사용자가 로그인 화면에 접근하면 홈·덱 목록 화면으로 이동한다.
