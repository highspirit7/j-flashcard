# 화면 사양서

## 1. 문서 목적

이 디렉터리는 J-Flashcard의 각 화면에 필요한 구성, 표시 데이터, 사용자 동작, 화면 상태, 입력 검증, 오류 처리, 완료 조건을 정의한다.

제품의 목표와 전체 기능 범위는 [Japanese_Flashcard_PRD.md](../Japanese_Flashcard_PRD.md)를 기준으로 한다.

## 3. 공통 문서 구조

각 화면 사양서는 가능한 한 다음 순서로 작성한다.

1. 화면 목적
2. 진입 및 이탈
3. 화면 구성
4. 표시 데이터
5. 사용자 동작
6. 화면 상태
7. 입력 및 검증
8. 오류 처리
9. 완료 조건

화면에 해당하지 않는 항목은 생략할 수 있지만, 사용자에게 보이는 상태와 실패 상황은 가능한 한 명시한다.

## 4. 상태 작성 규칙

화면 상태는 다음 관점에서 작성한다.

- 초기 상태: 화면에 처음 진입했을 때
- 로딩 상태: 데이터를 조회하거나 저장하는 중
- 성공 상태: 요청이 정상적으로 완료된 후
- 빈 상태: 표시할 데이터가 없을 때
- 오류 상태: 요청 또는 입력 검증에 실패했을 때
- 권한 상태: 로그인 여부나 데이터 소유권에 따라 접근이 달라질 때

## 5. 완료 조건 작성 규칙

완료 조건은 구현 여부가 아니라 사용자가 확인할 수 있는 결과로 작성한다.

```text
사용자 동작
→ 시스템 처리
→ 화면 또는 데이터의 기대 결과
```

각 조건은 테스트에서 독립적으로 확인할 수 있도록 구체적으로 작성한다.
