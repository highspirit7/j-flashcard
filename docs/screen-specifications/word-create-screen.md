# 단어 생성 페이지 사양서

## 1. 화면 목적

사용자가 선택한 덱에 새 단어(카드)를 등록할 수 있도록 한다. 단어(일본어 표기), 읽기, 뜻, 품사와 하나 이상의 예문(일본어 문장, 읽기, 한국어 뜻)을 입력하고 저장한다.

## 2. 진입 및 이탈

### 진입

- 덱 상세·단어 관리 화면에서 '새 카드 추가' 버튼을 클릭하면 이 화면으로 이동한다.
- 유효한 세션이 있고, 대상 덱을 소유한 사용자만 접근할 수 있다.

### 이탈

- 저장 버튼을 클릭하고 저장에 성공하면 덱 상세·단어 관리 화면으로 이동한다.
- 취소 버튼 또는 뒤로가기를 클릭하면 입력 내용을 저장하지 않고 덱 상세·단어 관리 화면으로 이동한다.
- 로그아웃하면 세션을 종료하고 로그인 화면으로 이동한다.

## 3. 화면 구성

| 영역      | 요소                   | 설명                                                                   |
| --------- | ---------------------- | ---------------------------------------------------------------------- |
| 헤더      | 뒤로가기 버튼          | 확인 없이 또는 변경 사항 확인 후 이전 화면으로 이동한다.               |
| 헤더      | 화면 제목 및 덱 이름   | 어느 덱에 카드를 추가하는지 표시한다.                                  |
| 입력 영역 | 단어(일본어 표기) 필드 | 한자/히라가나/가타가나 표기를 입력한다.                                |
| 입력 영역 | 읽기 필드              | 후리가나/히라가나 읽기를 입력한다.                                     |
| 입력 영역 | 뜻 필드                | 한국어 뜻을 입력한다.                                                  |
| 입력 영역 | 품사 선택              | 명사, 동사, 형용사, 부사, 조사, 조동사, 연결사, 감동사 등 중 선택한다. |
| 예문 영역 | 예문 목록              | 추가된 예문(일본어 문장, 읽기, 한국어 뜻)을 순서대로 표시한다.         |
| 예문 영역 | 예문 추가 버튼         | 새 예문 입력 행을 추가한다.                                            |
| 예문 항목 | 예문 문장/읽기/뜻 필드 | 각 예문의 일본어 문장, 발음, 한국어 뜻을 입력한다.                     |
| 예문 항목 | 예문 삭제 버튼         | 해당 예문 입력 행을 목록에서 제거한다.                                 |
| 하단      | 저장 버튼              | 입력값을 검증한 뒤 새 카드를 저장한다.                                 |
| 하단      | 취소 버튼              | 입력 내용을 저장하지 않고 이전 화면으로 이동한다.                      |

## 4. 표시 데이터

- 카드를 추가할 대상 덱의 이름(문맥 확인용)
- 사용자가 입력 중인 단어, 읽기, 뜻, 품사, 예문 목록(로컬 입력 상태)
- 저장은 현재 로그인한 사용자가 소유한 덱에 대해서만 허용한다.

## 5. 사용자 동작

| 사용자 동작                  | 시스템 처리                                   | 기대 결과                                                  |
| ---------------------------- | --------------------------------------------- | ---------------------------------------------------------- |
| 단어/읽기/뜻 필드 입력       | 입력값을 화면 상태에 반영한다.                | 입력한 값이 필드에 표시된다.                               |
| 품사 선택                    | 선택한 품사를 화면 상태에 반영한다.           | 선택한 품사가 표시된다.                                    |
| 예문 추가 버튼 클릭          | 새 예문 입력 행을 추가한다.                   | 빈 예문 입력 행이 목록 끝에 표시된다.                      |
| 예문 필드 입력               | 해당 예문의 값을 화면 상태에 반영한다.        | 입력한 값이 해당 예문 행에 표시된다.                       |
| 예문 삭제 버튼 클릭          | 해당 예문 입력 행을 목록에서 제거한다.        | 목록에서 해당 예문이 사라진다.                             |
| 저장 버튼 클릭               | 입력값을 검증하고, 통과 시 저장을 요청한다.   | 검증 실패 시 오류 표시, 성공 시 덱 상세 화면으로 이동한다. |
| 취소 버튼 또는 뒤로가기 클릭 | 저장 요청 없이 이전 화면으로 이동을 준비한다. | 입력 내용이 저장되지 않고 덱 상세 화면으로 이동한다.       |

## 6. 화면 상태

### 6.1 초기 상태

- 단어, 읽기, 뜻, 품사 필드가 비어 있다.
- 예문 목록은 처음에는 비어 있다.
- 저장 버튼은 필수 입력값이 채워지기 전까지 비활성화하거나, 클릭 시 검증 오류를 표시한다.

### 6.2 입력 중 상태

- 사용자가 입력한 값을 필드에 유지한다.
- 예문을 추가·삭제할 때마다 목록 순서를 유지하며 화면에 즉시 반영한다.

### 6.3 저장 요청 중 상태

- 저장 버튼 클릭 후 요청이 완료될 때까지 중복 제출을 방지한다.
- 사용자가 저장 진행 중임을 알 수 있도록 표시한다.

### 6.4 저장 성공 상태

- 새 카드가 대상 덱에 추가된다.
- 덱 상세·단어 관리 화면으로 이동하고, 새로 추가된 카드가 목록에 표시된다.

### 6.5 검증 오류 상태

- 필수 필드가 비어 있거나 형식에 맞지 않으면 저장을 요청하지 않는다.
- 오류가 있는 필드에 오류 메시지를 표시한다.
- 오류가 해결되지 않은 다른 필드의 입력값은 유지한다.

### 6.6 저장 실패 상태

- 저장 요청이 실패하면 입력한 값을 그대로 유지한다.
- 실패 원인을 안내하고 재시도할 수 있도록 한다.
- 실패한 요청을 성공한 것으로 표시하지 않는다.

### 6.7 세션 만료 상태

- 세션이 만료되었거나 인증되지 않은 경우 저장을 요청하지 않는다.
- 로그인 화면으로 이동한다.

## 7. 입력 및 검증

| 필드              | 필수 여부   | 검증                                                       |
| ----------------- | ----------- | ---------------------------------------------------------- |
| 단어(일본어 표기) | 필수        | 비어 있지 않아야 한다.                                     |
| 읽기              | 선택        | 입력하지 않아도 저장할 수 있다.                            |
| 뜻                | 필수        | 비어 있지 않아야 한다.                                     |
| 품사              | 필수        | 정의된 품사 목록 중 하나를 선택해야 한다.                  |
| 예문 목록         | 선택        | 0개 이상 추가할 수 있으며, 추가하지 않아도 저장할 수 있다. |
| 예문 문장(일본어) | 조건부 필수 | 예문 행이 존재하면 비어 있지 않아야 한다.                  |
| 예문 뜻(한국어)   | 조건부 필수 | 예문 행이 존재하면 비어 있지 않아야 한다.                  |
| 예문 읽기         | 선택        | 예문 행이 존재해도 비어 있는 채로 저장할 수 있다.          |

- 예문을 추가한 경우, 해당 예문의 문장과 뜻이 모두 채워져야 저장을 요청한다.
- 필수 필드 중 하나라도 비어 있으면 저장 요청을 보내지 않고 오류를 표시한다.

## 8. 오류 처리

| 상황                   | 처리                                                      |
| ---------------------- | --------------------------------------------------------- |
| 단어/뜻/품사 필드 누락 | 해당 필드에 오류를 표시하고 저장 요청을 보내지 않는다.    |
| 예문 문장 또는 뜻 누락 | 해당 예문 행에 오류를 표시하고 저장 요청을 보내지 않는다. |
| 저장 요청 실패         | 입력값을 유지하고 실패 메시지와 재시도 방법을 안내한다.   |
| 세션 만료 또는 미인증  | 저장을 요청하지 않고 로그인 화면으로 이동한다.            |
| 대상 덱을 찾을 수 없음 | 대상 데이터 없음 안내 후 홈·덱 목록 화면으로 이동한다.    |

오류 메시지는 사용자가 다음 행동을 알 수 있도록 작성하며, 데이터베이스나 인증 시스템의 내부 정보를 노출하지 않는다.

## 9. 완료 조건

- 단어, 읽기, 뜻, 품사 필드를 입력할 수 있다.
- 예문을 하나 이상 추가하고 각 예문의 일본어 문장, 읽기, 한국어 뜻을 입력할 수 있다.
- 예문 추가·삭제가 목록에 즉시 반영된다.
- 필수 입력값이 누락되면 저장되지 않고 해당 필드의 오류가 표시된다.
- 예문을 추가했지만 문장 또는 뜻이 비어 있으면 저장되지 않고 오류가 표시된다.
- 저장에 성공하면 새 카드가 대상 덱의 카드 목록에 표시되고, 덱 상세·단어 관리 화면으로 이동한다.
- 저장 요청 중에는 중복 제출이 방지된다.
- 저장에 실패하면 입력값이 유지되고 오류가 표시되며, 화면이 임의로 성공 상태로 바뀌지 않는다.
- 취소 버튼 또는 뒤로가기를 클릭하면 입력 내용이 저장되지 않고 덱 상세 화면으로 이동한다.
- 세션이 만료되었거나 인증되지 않은 사용자는 카드를 저장할 수 없다.
