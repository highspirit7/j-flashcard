# 홈·덱 목록 화면 사양서

## 1. 화면 목적

로그인한 사용자가 자신이 만든 덱 목록과 각 덱의 오늘 학습 예정 카드 수를 확인하고, 덱을 생성하거나 덱 이름을 클릭하여 덱 상세·단어 관리 화면으로 이동할 수 있도록 한다.

## 2. 진입 및 이탈

### 진입

- 로그인에 성공하면 홈·덱 목록 화면으로 이동한다.
- 유효한 세션이 있는 사용자가 앱에 접근하면 홈·덱 목록 화면을 표시한다.
- 덱 상세 화면 등 보호된 화면에서 홈으로 이동하면 이 화면을 표시한다.

### 이탈

- 덱 이름을 클릭하면 해당 덱의 상세·단어 관리 화면으로 이동한다.
- 덱의 학습 시작 동작을 선택하면 해당 덱의 학습 화면으로 이동한다.
- 로그아웃하면 세션을 종료하고 로그인 화면으로 이동한다.

## 3. 화면 구성

| 영역        | 요소                   | 설명                                                    |
| ----------- | ---------------------- | ------------------------------------------------------- |
| 헤더        | 앱 이름 또는 화면 제목 | J-Flashcard 또는 홈 화면 제목을 표시한다.               |
| 헤더        | 현재 사용자 정보       | 현재 로그인한 사용자를 식별할 수 있는 정보를 표시한다.  |
| 헤더        | 로그아웃 버튼          | 현재 세션을 종료한다.                                   |
| 콘텐츠 헤더 | 화면 제목              | 사용자의 덱 목록 화면임을 표시한다.                     |
| 콘텐츠 헤더 | 새 덱 추가 버튼        | 덱 생성 모달을 연다.                                    |
| 모달        | 덱 생성 모달           | 덱 이름, 설명, 카테고리를 입력하고 저장하거나 취소한다. |
| 목록 영역   | 덱 카드 또는 목록 항목 | 덱 이름, 설명, 카테고리, 학습 예정 카드 수를 표시한다.  |
| 덱 정보     | New 카드 수            | 아직 학습하지 않은 카드 수를 표시한다.                  |
| 덱 정보     | Learning 카드 수       | 학습 중인 카드 수를 표시한다.                           |
| 덱 정보     | Review 카드 수         | 복습 예정인 카드 수를 표시한다.                         |
| 덱 동작     | 덱 이름                | 클릭하면 해당 덱의 상세·단어 관리 화면으로 이동한다.    |
| 덱 동작     | 학습 시작 버튼         | 해당 덱의 학습 화면으로 이동한다.                       |

## 4. 표시 데이터

각 덱에는 다음 정보를 표시한다.

- 덱 이름
- 덱 설명
- 덱 카테고리
- 전체 카드 수
- 오늘 학습 예정 카드 수
- New 카드 수
- Learning 카드 수
- Review 카드 수
- 덱 생성일 또는 마지막 수정일

- 카드 수는 현재 로그인한 사용자의 데이터만 기준으로 계산한다.
- 오늘 학습 예정 카드 수는 New, Learning, Review 카드 수의 기준을 일관되게 적용하여 표시한다.
- 카드 수를 불러올 수 없는 경우 잘못된 숫자를 성공 상태처럼 표시하지 않는다.

## 5. 사용자 동작

| 사용자 동작          | 시스템 처리                            | 기대 결과                                       |
| -------------------- | -------------------------------------- | ----------------------------------------------- |
| 덱 이름 클릭         | 클릭한 덱의 식별자를 확인한다.         | 해당 덱의 상세·단어 관리 화면으로 이동한다.     |
| 학습 시작 버튼 클릭  | 선택한 덱의 학습 대상 카드를 조회한다. | 해당 덱의 학습 화면으로 이동한다.               |
| 새 덱 추가 버튼 클릭 | 덱 생성 모달을 연다.                   | 덱 이름, 설명, 카테고리를 입력할 수 있다.       |
| 덱 생성 모달 저장    | 입력값을 검증하고 덱을 저장한다.       | 모달이 닫히고 생성한 덱이 목록에 표시된다.      |
| 덱 생성 모달 취소    | 생성 작업을 취소한다.                  | 입력 내용을 저장하지 않고 모달을 닫는다.        |
| 로그아웃 버튼 클릭   | 현재 세션을 종료한다.                  | 로그인 화면으로 이동한다.                       |
| 새로고침             | 세션과 덱 목록을 다시 확인한다.        | 유효한 세션이면 저장된 덱 목록이 다시 표시된다. |

## 6. 화면 상태

### 6.1 초기 상태

- 현재 사용자 정보와 화면 제목을 표시한다.
- 덱 목록 조회를 시작한다.
- 덱 목록을 불러오는 동안 목록 영역에 로딩 상태를 표시한다.
- 로딩 중에도 로그아웃 동작은 일관되게 처리한다.

### 6.2 덱 목록 표시 상태

- 현재 사용자가 소유한 덱만 표시한다.
- 각 덱의 기본 정보와 오늘 학습 예정 카드 수를 표시한다.
- 덱 이름을 클릭하여 덱 상세·단어 관리 화면으로 이동할 수 있다.
- 학습 시작 버튼을 클릭하여 해당 덱의 학습 화면으로 이동할 수 있다.

### 6.3 빈 목록 상태

- 사용자의 덱이 없으면 덱이 없다는 안내를 표시한다.
- 새 덱 추가 동작을 바로 실행할 수 있도록 한다.
- 덱이 없다는 상태를 오류 상태와 구분한다.

### 6.4 덱 생성 모달 표시 상태

- 덱 이름, 설명, 카테고리를 입력할 수 있다.
- 저장하지 않고 취소하거나 닫으면 덱이 생성되지 않는다.

### 6.5 덱 생성 요청 중

- 저장 요청 중에는 저장 동작을 비활성화하여 중복 생성을 방지한다.
- 사용자가 저장 요청 진행 중임을 알 수 있도록 표시한다.
- 저장이 완료되면 모달을 닫고 새 덱을 목록에 표시한다.

### 6.6 오류 상태

- 덱 목록 조회에 실패하면 오류 메시지와 재시도 동작을 표시한다.
- 덱 생성에 실패하면 입력한 값을 유지하고 다시 시도할 수 있도록 한다.
- 오류가 발생한 요청을 성공한 것으로 처리하지 않는다.

### 6.7 세션 만료 상태

- 세션이 만료되었거나 인증되지 않은 경우 덱 데이터를 조회하지 않는다.
- 로그인 화면으로 이동한다.
- 사용자의 덱 정보나 오류 원인을 인증되지 않은 상태에서 노출하지 않는다.

## 7. 입력 및 검증

| 필드     | 필수 여부     | 검증                                         |
| -------- | ------------- | -------------------------------------------- |
| 덱 이름  | 필수          | 비어 있지 않아야 한다.                       |
| 덱 설명  | 선택          | 입력하지 않아도 저장할 수 있다.              |
| 카테고리 | PRD 기준 선택 | 사용할 경우 허용된 카테고리 값으로 저장한다. |

- 덱 이름이 비어 있으면 저장 요청을 보내지 않는다.
- 덱 이름의 최대 길이와 중복 허용 여부는 구현 전에 결정한다.
- 설명을 입력하지 않은 경우 빈 값으로 저장하거나 표시를 생략할 수 있다.

## 8. 오류 처리

| 상황                     | 처리                                                      |
| ------------------------ | --------------------------------------------------------- |
| 덱 목록 조회 실패        | 오류 메시지와 재시도 동작을 표시한다.                     |
| 덱 이름이 비어 있음      | 덱 이름 필드에 오류를 표시하고 저장 요청을 보내지 않는다. |
| 덱 생성 실패             | 입력값을 유지하고 저장 실패 메시지를 표시한다.            |
| 세션 만료 또는 권한 없음 | 로그인 화면으로 이동한다.                                 |
| 학습 대상 조회 실패      | 학습 화면으로 이동하지 않고 현재 화면에 오류를 표시한다.  |

오류 메시지는 사용자가 다음 행동을 알 수 있도록 작성하며, 데이터베이스나 인증 시스템의 내부 정보를 노출하지 않는다.

## 9. 완료 조건

- 로그인한 사용자의 덱 목록만 표시된다.
- 각 덱의 이름, 설명, 카테고리, 카드 수가 표시된다.
- 각 덱의 New, Learning, Review 카드 수와 오늘 학습 예정 카드 수가 표시된다.
- 덱 목록을 불러오는 동안 로딩 상태가 표시된다.
- 덱이 없을 때 오류와 구분되는 빈 상태가 표시된다.
- 새 덱 추가 버튼을 클릭하면 덱 생성 모달이 표시된다.
- 덱 생성 모달에서 덱 이름, 설명, 카테고리를 입력할 수 있다.
- 덱 생성 모달을 저장하지 않고 닫으면 덱이 생성되지 않는다.
- 덱 이름이 비어 있으면 덱이 생성되지 않고 입력 오류가 표시된다.
- 정상적으로 생성하면 모달이 닫히고 새 덱이 목록에 표시된다.
- 덱 이름을 클릭하면 해당 덱의 상세·단어 관리 화면으로 이동한다.
- 학습 시작을 선택하면 해당 덱의 학습 화면으로 이동한다.
- 덱 목록 조회, 생성에 실패하면 실패 상태를 표시하고 성공한 것처럼 화면을 변경하지 않는다.
- 로그아웃하면 세션이 종료되고 로그인 화면으로 이동한다.
- 새로고침 후에도 유효한 세션과 저장된 덱 목록이 유지된다.
