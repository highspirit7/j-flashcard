# 단어 편집 페이지 사양서

## 1. 화면 목적

사용자가 선택한 카드의 단어(일본어 표기), 읽기, 뜻, 품사와 예문을 수정할 수 있도록 한다. 카드 내용만 갱신하며, 학습 상태와 FSRS 스케줄링 정보는 변경하지 않는다.

## 2. 진입 및 이탈

### 진입

- 덱 상세·단어 관리 화면에서 단어 행의 편집 버튼을 클릭하면 이 화면으로 이동한다.
- 유효한 세션이 있고, 대상 카드가 현재 사용자가 소유한 덱에 속할 때만 접근할 수 있다.

### 이탈

- 저장 버튼을 클릭하고 저장에 성공하면 덱 상세·단어 관리 화면으로 이동한다.
- 취소 버튼 또는 뒤로가기를 클릭하면 변경 내용을 저장하지 않고 덱 상세·단어 관리 화면으로 이동한다.
- 변경 사항이 있는 상태에서 취소 또는 뒤로가기를 시도하면 변경 내용을 버릴지 확인한다.
- 로그아웃하면 세션을 종료하고 로그인 화면으로 이동한다.

## 3. 화면 구성

| 영역      | 요소                   | 설명                                                                    |
| --------- | ---------------------- | ----------------------------------------------------------------------- |
| 헤더      | 뒤로가기 버튼          | 변경 사항이 없으면 이전 화면으로, 있으면 변경 취소 확인 UI를 표시한다.  |
| 헤더      | 화면 제목 및 덱 이름   | 수정 중인 카드와 소속 덱의 맥락을 표시한다.                             |
| 입력 영역 | 단어(일본어 표기) 필드 | 저장된 한자/히라가나/가타가나 표기를 표시하고 수정한다.                 |
| 입력 영역 | 읽기 필드              | 저장된 후리가나/히라가나 읽기를 표시하고 수정한다.                      |
| 입력 영역 | 뜻 필드                | 저장된 한국어 뜻을 표시하고 수정한다.                                   |
| 입력 영역 | 품사 선택              | 저장된 품사를 표시하고 정의된 목록 중 하나로 수정한다.                  |
| 예문 영역 | 예문 목록              | 저장된 예문(일본어 문장, 읽기, 한국어 뜻)을 순서대로 표시하고 수정한다. |
| 예문 영역 | 예문 추가 버튼         | 새 예문 입력 행을 추가한다.                                             |
| 예문 항목 | 예문 문장/읽기/뜻 필드 | 각 예문의 일본어 문장, 발음, 한국어 뜻을 수정한다.                      |
| 예문 항목 | 예문 삭제 버튼         | 해당 예문을 삭제 목록에 반영한다.                                       |
| 하단      | 저장 버튼              | 변경 사항이 있고 입력값이 유효할 때 카드 내용을 저장한다.               |
| 하단      | 취소 버튼              | 변경 내용을 저장하지 않고 이전 화면으로 이동한다.                       |
| 확인 UI   | 변경 취소 확인         | 저장하지 않은 변경 내용을 버릴지 확인한다.                              |

## 4. 표시 데이터

- 수정할 카드가 속한 덱의 이름
- 카드의 단어, 읽기, 뜻, 품사, 예문 목록
- 카드의 학습 상태는 덱 상세 화면에서 확인할 수 있으며, 이 화면에서 카드 내용을 수정해도 변경하지 않는다.
- 카드의 `state`, `stability`, `difficulty`, `interval`, `dueDate`, `repetitions`, `lapses`, `lastReviewedAt`은 수정 대상이 아니다.

## 5. 사용자 동작

| 사용자 동작                     | 시스템 처리                                           | 기대 결과                                                    |
| ------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------ |
| 화면 진입                       | 카드와 예문 데이터를 조회한다.                        | 기존 카드 정보가 각 입력 필드에 표시된다.                    |
| 단어/읽기/뜻 필드 수정          | 수정값을 화면 상태에 반영하고 변경 사항을 감지한다.   | 수정한 값이 표시되고 저장 버튼을 사용할 수 있다.             |
| 품사 선택                       | 선택값을 화면 상태에 반영하고 변경 사항을 감지한다.   | 선택한 품사가 표시되고 저장 버튼을 사용할 수 있다.           |
| 예문 추가 버튼 클릭             | 새 예문 입력 행을 추가하고 변경 사항을 감지한다.      | 빈 예문 입력 행이 목록 끝에 표시된다.                        |
| 예문 필드 수정                  | 해당 예문의 수정값을 화면 상태에 반영한다.            | 수정한 값이 해당 예문 행에 표시된다.                         |
| 예문 삭제 버튼 클릭             | 해당 예문을 저장 시 삭제할 목록에 반영한다.           | 해당 예문 행이 목록에서 사라지고 저장 버튼을 사용할 수 있다. |
| 저장 버튼 클릭                  | 입력값을 검증하고, 통과 시 카드 내용 변경을 요청한다. | 검증 실패 시 오류 표시, 성공 시 덱 상세 화면으로 이동한다.   |
| 변경 후 취소 또는 뒤로가기 클릭 | 변경 취소 확인 UI를 표시한다.                         | 계속 편집하거나 변경 내용을 버릴 수 있다.                    |
| 변경 취소 확인                  | 저장하지 않은 변경 내용을 폐기한다.                   | 덱 상세·단어 관리 화면으로 이동한다.                         |
| 변경 취소 취소                  | 현재 입력 상태를 유지한다.                            | 단어 편집 화면에 남아 계속 수정할 수 있다.                   |

## 6. 화면 상태

### 6.1 초기 및 조회 중 상태

- 카드와 예문 데이터를 조회하는 동안 로딩 상태를 표시한다.
- 조회가 완료되기 전에는 입력 필드와 저장 버튼을 사용할 수 없다.

### 6.2 편집 가능 상태

- 조회에 성공하면 저장된 카드 정보와 예문 목록을 입력 필드에 표시한다.
- 변경 사항이 없을 때 저장 버튼은 비활성화한다.
- 예문 목록은 비어 있을 수 있으며, 필요하면 예문 입력 행을 추가할 수 있다.

### 6.3 변경 사항 감지 상태

- 단어, 읽기, 뜻, 품사, 예문의 추가·수정·삭제 여부를 저장 시점의 데이터와 비교한다.
- 하나 이상의 변경 사항이 있으면 저장 버튼을 활성화한다.
- 변경 내용을 원래 값으로 되돌리면 저장 버튼을 다시 비활성화한다.

### 6.4 저장 요청 중 상태

- 저장 요청이 완료될 때까지 중복 제출과 화면 이탈을 방지한다.
- 사용자가 저장 진행 중임을 알 수 있도록 표시한다.

### 6.5 저장 성공 상태

- 변경된 카드 내용과 예문이 저장된다.
- 카드의 학습 상태 및 FSRS 스케줄링 값은 저장 전 값으로 유지된다.
- 덱 상세·단어 관리 화면으로 이동하고, 갱신된 카드 정보가 목록에 표시된다.

### 6.6 검증 오류 상태

- 필수 필드가 비어 있거나 형식에 맞지 않으면 저장을 요청하지 않는다.
- 오류가 있는 필드 또는 예문 행에 오류 메시지를 표시한다.
- 사용자가 입력한 다른 값과 변경 사항은 유지한다.

### 6.7 조회 또는 저장 실패 상태

- 조회에 실패하면 오류 메시지와 재시도 동작을 표시한다.
- 저장에 실패하면 현재 입력값과 변경 사항을 유지하고 재시도할 수 있도록 한다.
- 실패한 요청을 성공한 것으로 표시하거나 덱 상세 화면으로 이동하지 않는다.

### 6.8 세션 만료 또는 카드 없음 상태

- 세션이 만료되었거나 인증되지 않은 경우 카드 데이터를 표시하지 않는다.
- 대상 카드가 삭제되었거나 존재하지 않으면 오류를 안내한다.
- 세션 만료 시 로그인 화면으로 이동한다.

## 7. 입력 및 검증

| 필드              | 필수 여부   | 검증                                              |
| ----------------- | ----------- | ------------------------------------------------- |
| 단어(일본어 표기) | 필수        | 비어 있지 않아야 한다.                            |
| 읽기              | 선택        | 입력하지 않아도 저장할 수 있다.                   |
| 뜻                | 필수        | 비어 있지 않아야 한다.                            |
| 품사              | 필수        | 정의된 품사 목록 중 하나를 선택해야 한다.         |
| 예문 목록         | 선택        | 0개 이상 유지하거나 추가할 수 있다.               |
| 예문 문장(일본어) | 조건부 필수 | 예문 행이 존재하면 비어 있지 않아야 한다.         |
| 예문 뜻(한국어)   | 조건부 필수 | 예문 행이 존재하면 비어 있지 않아야 한다.         |
| 예문 읽기         | 선택        | 예문 행이 존재해도 비어 있는 채로 저장할 수 있다. |

- 예문을 추가하거나 수정한 경우, 해당 예문의 문장과 뜻이 모두 채워져야 저장을 요청한다.
- 변경 사항이 없으면 저장 요청을 보내지 않는다.
- 카드 내용만 갱신하며 학습 상태와 FSRS 스케줄링 값은 요청에 포함하지 않는다.

## 8. 오류 처리

| 상황                         | 처리                                                                |
| ---------------------------- | ------------------------------------------------------------------- |
| 카드 또는 예문 조회 실패     | 오류 메시지와 재시도 동작을 표시한다.                               |
| 단어/뜻/품사 필드 누락       | 해당 필드에 오류를 표시하고 저장 요청을 보내지 않는다.              |
| 예문 문장 또는 뜻 누락       | 해당 예문 행에 오류를 표시하고 저장 요청을 보내지 않는다.           |
| 변경 사항 없음               | 저장 버튼을 비활성화하고 저장 요청을 보내지 않는다.                 |
| 저장 요청 실패               | 입력값과 변경 사항을 유지하고 실패 메시지와 재시도 방법을 안내한다. |
| 저장되지 않은 변경 내용 이탈 | 변경 취소 확인 UI를 표시하고, 확인 전에는 화면을 이동하지 않는다.   |
| 세션 만료 또는 미인증        | 카드 데이터를 표시하거나 저장하지 않고 로그인 화면으로 이동한다.    |
| 대상 카드가 없음             | 대상 데이터 없음 안내 후 덱 상세·단어 관리 목록 화면으로 이동한다.  |

오류 메시지는 사용자가 다음 행동을 알 수 있도록 작성하며, 데이터베이스나 인증 시스템의 내부 정보를 노출하지 않는다.

## 9. 완료 조건

- 기존 카드의 단어, 읽기, 뜻, 품사, 예문이 화면에 미리 표시되고 수정할 수 있다.
- 예문을 추가·수정·삭제할 수 있으며, 변경 사항이 목록에 즉시 반영된다.
- 변경 사항이 없으면 저장 버튼이 비활성화되고 저장 요청이 발생하지 않는다.
- 하나 이상의 변경 사항이 있으면 저장 버튼을 사용할 수 있다.
- 필수 입력값 또는 추가된 예문의 문장·뜻이 누락되면 저장되지 않고 해당 위치에 오류가 표시된다.
- 저장에 성공하면 수정한 카드와 예문이 덱 상세·단어 관리 화면의 목록에 반영된다.
- 카드 내용을 수정해도 `state`, `stability`, `difficulty`, `interval`, `dueDate`, `repetitions`, `lapses`, `lastReviewedAt`은 변경되지 않는다.
- 저장 요청 중에는 중복 제출과 화면 이탈이 방지된다.
- 저장에 실패하면 입력값과 변경 사항이 유지되고 오류가 표시되며, 화면이 임의로 성공 상태로 바뀌지 않는다.
- 변경 사항이 있는 상태에서 취소 또는 뒤로가기를 시도하면 변경 내용을 버릴지 확인할 수 있다.
- 세션이 만료되었거나 인증되지 않은 사용자는 카드 데이터를 조회하거나 저장할 수 없다.
