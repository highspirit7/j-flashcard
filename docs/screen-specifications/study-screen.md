# 학습 화면 사양서

## 1. 화면 목적

사용자가 선택한 덱의 학습 대상 카드를 한 장씩 확인하고, 카드 뒷면을 본 뒤 `Again`, `Hard`, `Good`, `Easy` 평가를 선택하여 다음 복습 일정을 저장할 수 있도록 한다.

## 2. 진입 및 이탈

### 진입

- 덱 상세·단어 관리 화면에서 '학습 시작' 버튼을 클릭하면 이 화면으로 이동한다.
- 유효한 세션이 있고, 대상 덱을 소유한 사용자만 접근할 수 있다.

### 이탈

- 뒤로가기 또는 학습 종료 버튼을 클릭하면 덱 상세·단어 관리 화면으로 이동한다.
- 학습 대상 카드가 모두 처리되면 학습 완료 상태를 표시하며, 덱 상세·단어 관리 화면으로 돌아갈 수 있다.
- 로그아웃하면 세션을 종료하고 로그인 화면으로 이동한다.

## 3. 화면 구성

| 영역      | 요소                         | 설명                                                                      |
| --------- | ---------------------------- | ------------------------------------------------------------------------- |
| 헤더      | 뒤로가기 또는 학습 종료 버튼 | 현재 학습을 종료하고 덱 상세·단어 관리 화면으로 이동한다.                 |
| 헤더      | 덱 이름                      | 현재 학습 중인 덱을 표시한다.                                             |
| 진행 영역 | 진행률 표시                  | 현재 세션에서 처리한 카드 수와 전체 대상 카드 수를 표시한다.              |
| 진행 영역 | 진행률 바                    | 학습 진행 상태를 시각적으로 표시한다.                                     |
| 진행 영역 | 남은 카드 수                 | 현재 세션에서 아직 평가하지 않은 카드 수를 표시한다.                      |
| 카드 영역 | 플래시카드 앞면              | 카드의 일본어 표기를 표시한다.                                            |
| 카드 영역 | 플래시카드 뒷면              | 읽기, 품사, 뜻, 예문(일본어 문장, 읽기, 한국어 뜻)을 표시한다.            |
| 카드 영역 | 카드 뒤집기 동작             | 카드 영역을 클릭 또는 터치하면 3D Flip 애니메이션으로 앞·뒷면을 전환한다. |
| 평가 영역 | 예상 복습 간격               | 각 평가에 따른 다음 복습 간격을 표시한다.                                 |
| 평가 영역 | `Again` 버튼                 | 기억하지 못한 카드로 평가하고 다음 일정을 저장한다.                       |
| 평가 영역 | `Hard` 버튼                  | 어렵게 기억한 카드로 평가하고 다음 일정을 저장한다.                       |
| 평가 영역 | `Good` 버튼                  | 무난하게 기억한 카드로 평가하고 다음 일정을 저장한다.                     |
| 평가 영역 | `Easy` 버튼                  | 쉽게 기억한 카드로 평가하고 다음 일정을 저장한다.                         |
| 상태 영역 | 빈 상태 또는 완료 상태       | 학습할 카드가 없거나 모든 카드를 처리한 경우를 안내한다.                  |
| 상태 영역 | 오류 및 재시도 동작          | 대상 카드 조회 또는 평가 저장 실패를 안내하고 재시도할 수 있게 한다.      |

## 4. 표시 데이터

- 현재 학습 중인 덱 이름
- 현재 카드의 일본어 표기, 읽기, 품사, 뜻, 예문 목록
- 전체 학습 대상 카드 수, 처리한 카드 수, 남은 카드 수, 진행률
- 각 평가(`Again`, `Hard`, `Good`, `Easy`)에 대한 예상 복습 간격

- 학습 대상은 현재 로그인한 사용자가 소유한 덱에 속하고, 학습 시점에 복습이 필요한 카드만으로 구성한다.
- 예문이 없는 카드는 예문 영역을 비어 있는 상태로 표시하며, 오류로 처리하지 않는다.
- 예상 복습 간격은 현재 카드의 학습 상태와 평가 시점을 기준으로 계산한다.

## 5. 사용자 동작

| 사용자 동작                  | 시스템 처리                                                | 기대 결과                                                  |
| ---------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------- |
| 학습 화면 진입               | 대상 덱의 학습 카드를 조회하고 세션을 준비한다.            | 카드가 있으면 첫 카드, 없으면 빈 상태가 표시된다.          |
| 카드 영역 클릭 또는 터치     | 현재 카드의 앞면과 뒷면을 전환한다.                        | 3D Flip 애니메이션 후 반대쪽 카드 내용이 표시된다.         |
| 카드 앞면에서 평가 버튼 클릭 | 평가 요청을 차단한다.                                      | 일정이 저장되지 않고 카드 뒷면을 먼저 확인하도록 안내한다. |
| 카드 뒷면에서 평가 버튼 클릭 | 선택한 평가로 다음 복습 일정과 카드 상태를 계산한다.       | 해당 평가의 저장 요청이 시작된다.                          |
| 평가 저장 성공               | 계산된 학습 결과를 저장하고 다음 카드를 선택한다.          | 다음 카드의 앞면 또는 학습 완료 상태가 표시된다.           |
| `Again` 평가 저장 성공       | 필요한 경우 현재 세션의 재학습 대기열에 카드를 추가한다.   | 다른 카드 처리 후 해당 카드가 세션 내에 다시 표시된다.     |
| 오류 상태의 재시도 클릭      | 실패한 대상 카드 조회 또는 평가 저장 요청을 다시 시도한다. | 성공 시 카드 또는 다음 학습 상태가 표시된다.               |
| 뒤로가기 또는 학습 종료 클릭 | 현재 세션을 종료하고 화면 전환을 준비한다.                 | 덱 상세·단어 관리 화면으로 이동한다.                       |

## 6. 화면 상태

### 6.1 초기 및 학습 대상 조회 중 상태

- 덱 정보와 학습 화면 제목을 표시한다.
- 학습 대상 카드를 조회하는 동안 카드 영역과 평가 버튼에 로딩 상태를 표시한다.
- 조회가 완료되기 전에는 카드 뒤집기와 평가를 실행할 수 없다.

### 6.2 카드 앞면 상태

- 현재 카드의 일본어 표기만 표시한다.
- 카드 영역을 클릭하거나 터치하면 뒷면으로 전환한다.
- 평가 버튼은 비활성화한다.
- 각 평가에 해당하는 예상 복습 간격은 확인할 수 있다.

### 6.3 카드 뒷면 상태

- 현재 카드의 읽기, 품사, 뜻, 예문을 표시한다.
- 카드 영역을 클릭하거나 터치하면 앞면으로 전환할 수 있다.
- 평가 버튼을 활성화한다.
- 평가 버튼별 예상 복습 간격을 표시한다.

### 6.4 평가 저장 중 상태

- 선택한 평가의 다음 복습 일정과 카드 상태를 계산하고 저장한다.
- 저장이 완료될 때까지 모든 평가 버튼과 카드 뒤집기 동작을 비활성화한다.
- 사용자가 평가 저장 진행 중임을 알 수 있도록 표시한다.

### 6.5 다음 카드 상태

- 평가 저장에 성공하면 처리한 카드 수와 남은 카드 수를 갱신한다.
- 다음 카드를 앞면 상태로 표시한다.
- `Again`으로 평가된 카드가 재학습 대상이면 현재 세션의 대기열에 다시 추가한다.

### 6.6 빈 학습 대상 상태

- 학습 시작 시점에 대상 카드가 없으면 학습할 카드가 없다는 안내를 표시한다.
- 빈 상태는 대상 카드 조회 실패와 구분한다.
- 덱 상세·단어 관리 화면으로 돌아갈 수 있다.

### 6.7 학습 완료 상태

- 현재 세션의 모든 학습 대상 카드와 재학습 대기열의 카드가 처리되면 완료 상태를 표시한다.
- 완료한 카드 수를 표시하고 덱 상세·단어 관리 화면으로 돌아갈 수 있다.

### 6.8 오류 상태

- 대상 카드 조회에 실패하면 오류 메시지와 재시도 동작을 표시한다.
- 평가 저장에 실패하면 현재 카드와 뒷면 상태를 유지하고 재시도할 수 있도록 한다.
- 실패한 평가를 성공한 것으로 표시하거나 다음 카드로 이동하지 않는다.

### 6.9 세션 만료 상태

- 세션이 만료되었거나 인증되지 않은 경우 카드 데이터를 조회하거나 평가를 저장하지 않는다.
- 로그인 화면으로 이동한다.

## 7. 입력 및 검증

| 항목        | 사용 가능 조건                         | 검증                                                          |
| ----------- | -------------------------------------- | ------------------------------------------------------------- |
| 카드 뒤집기 | 대상 카드 조회 완료, 평가 저장 중 아님 | 클릭 또는 터치할 때 현재 카드의 앞·뒷면만 전환한다.           |
| 평가 버튼   | 카드 뒷면 표시, 평가 저장 중 아님      | `again`, `hard`, `good`, `easy` 중 하나만 선택해야 한다.      |
| 재시도      | 조회 또는 저장 실패 상태               | 실패한 요청에 필요한 카드와 평가 정보를 유지해 다시 요청한다. |

- 카드 뒷면을 보기 전에는 평가 요청을 보내지 않는다.
- 평가 시 현재 카드와 선택한 평가를 기준으로 다음 복습 일정과 학습 상태를 계산한다.
- 평가 저장에 성공한 후에만 다음 카드 또는 완료 상태로 전환한다.

## 8. 오류 처리

| 상황                     | 처리                                                                              |
| ------------------------ | --------------------------------------------------------------------------------- |
| 학습 대상 카드 조회 실패 | 오류 메시지와 재시도 동작을 표시하며 카드나 진행률을 성공 상태로 표시하지 않는다. |
| 카드 앞면에서 평가 시도  | 평가 저장 요청을 보내지 않고 카드 뒷면을 먼저 확인하도록 안내한다.                |
| 평가 저장 실패           | 현재 카드와 뒷면 상태를 유지하고 실패 메시지와 재시도 동작을 표시한다.            |
| 학습 대상 카드 없음      | 대상 데이터 없음 안내 후 덱 상세·단어 관리 목록 화면으로 이동한다.                |
| 세션 만료 또는 미인증    | 카드 데이터나 학습 정보를 노출하지 않고 로그인 화면으로 이동한다.                 |
| 대상 덱을 찾을 수 없음   | 대상 데이터 없음 안내 후 홈·덱 목록 화면으로 이동한다.                            |

오류 메시지는 사용자가 다음 행동을 알 수 있도록 작성하며, 데이터베이스나 인증 시스템의 내부 정보를 노출하지 않는다.

## 9. 완료 조건

- 덱에서 학습을 시작하면 학습 대상 카드가 표시된다.
- 카드 앞면에는 일본어 표기가 표시되고, 클릭 또는 터치하면 3D Flip 애니메이션으로 뒷면으로 전환된다.
- 카드 뒷면에는 읽기, 품사, 뜻, 예문이 표시된다.
- 현재 진행률과 남은 카드 수가 표시된다.
- 카드 뒷면을 확인하기 전에는 `Again`, `Hard`, `Good`, `Easy` 평가 버튼을 사용할 수 없다.
- 카드 뒷면에서 각 평가 버튼을 사용할 수 있고, 각 버튼에 해당하는 예상 복습 간격이 표시된다.
- 평가를 선택하면 카드 상태, 다음 복습 일정, 복습 간격이 계산되어 저장된다.
- 평가 저장에 성공한 후에만 다음 카드 또는 학습 완료 상태가 표시된다.
- `Again` 선택 시 재학습이 필요한 카드는 현재 세션에 다시 표시된다.
- 학습 대상 카드가 없을 때는 오류와 구분되는 빈 상태가 표시된다.
- 평가 저장에 실패하면 현재 카드가 유지되고 오류를 확인한 뒤 재시도할 수 있다.
- 모바일과 데스크톱 화면에서 카드, 진행 영역, 평가 버튼이 서로 겹치지 않는다.
- 세션이 만료되었거나 인증되지 않은 사용자는 학습 카드 데이터를 조회하거나 평가를 저장할 수 없다.
